Guillotine Repair Excel Helper

Import an Excel worksheet, select repair subjects, assign quantities, and print a paginated repair request form.

How to Use This App

Use this tool to import an Excel or CSV job file, select the fields needed for identification, build a guillotine repair list, and print or save a completed material-handoff form. You can also save the complete request as a JSON file and reopen it later for revisions.

Step-by-Step Instructions

Start a new request or load a saved request. For a new request, complete the Request Information fields below. To continue an older request, select Load Repair Request JSON in the Repair Export List section.
Import the Excel or CSV job file. Choose or drag in the source file, select the correct data worksheet and layout worksheet, and enter the row containing the column headers. The data begins on the rows below that header.
Choose the columns that should appear on the repair form. Check only the fields needed to identify each card or subject, such as card number, description, form, position, or other job-specific identifiers.
Search for and add each repair subject. Select the best Filter/Search Column, type a value in Search Available Rows, choose the matching result, enter the Repair QTY Needed, and select Add Repair to Export.
Review and organize the repair list. Correct quantities directly in the list, use the arrow buttons to change print order, or remove incorrect entries. Confirm the calculated sheet requirement and enter the number actually provided when it differs.
Save or print the completed request. Select an authorized save folder, then use Save JSON to Folder to preserve an editable copy or Save PDF to Folder for the handoff form. Use Print / Browser PDF when a normal print dialog is preferred. The app automatically fits complete rows to each page and places the signature, receipt, and delivery-location sections only on the final page.

Field Reference

Project Name Name used to identify the project or repair request.
Job # Production job number associated with the material.
Form # Form, version, or production-form identifier.
Date Requested Date the repair material was requested.
Request Type Return Blanks requests replacement blank material. Subjects Only identifies only the listed subjects or cards requiring repair.
Location Details Delivery or staging location, such as a skid, rack, department, machine, or other handoff point. Maximum 350 characters.
Worksheet Tab within the imported workbook containing the job data.
Header Row Exact worksheet row containing the field names. This is commonly row 1, but may vary by job.
Columns to Print Imported fields displayed for each repair subject on the printed form.
Filter/Search Column Worksheet field used to locate records, such as Card Number or Card Description.
Repair QTY Needed Number of damaged copies or repair units required for the selected subject.
Sheets Needed Automatic recommendation based on the highest Repair QTY in the repair list.
Sheets / Builds Provided Actual quantity handed off by the MVP supervisor. Leave blank to use the automatic recommendation, or enter a manual value when the provided quantity differs.
Printed Pages Number of pages currently required after accounting for wrapped text and the final signature sections.
Recommended practice: Select the save folder before starting exports, then save a JSON copy before printing when the request may need later revisions. The JSON file retains the imported rows, selected columns, request fields, repair quantities, ordering, sheet settings, parsed running-sheet card positions, and the detected up count.
